'우주사업부 재직 인원' 카드에 전월대비 차이를 넣고 싶음. '350명'이라는 숫자 옆에 '+17' 이런식으로. 단 '350명 글자보다는 작게, 윗첨자로.

'평균 근속연수' 카드에서 '그룹 입사일 기준, 임원 제외'에 ''26.07 기준'이라는 워딩도 추가해. 

'부서별 레벨 피라미드' 카드에서 7~3의 숫자를 각각 'L7, L6, L5, L4, L3'로 바꾸고, 3은 'L3이하'로 바꿔. '계약직' 삭제해. 현재의 막대 바가 너무 얇으니 좀 더 두껍게 바꿔. 막대바끼리 색상이 너무 비슷해서 잘 구분이 안되는 것 같아. '기타(T직군)'을 추가해서 raw data 중 '직급명' 칼럼에서 '제주우주센터'의 'TJ(사원)'은 'L3이하'로 카운트해. 

Part1과 Part2 모두에서 피라미드를 나타내는 카드들은 해당 부서나 사업부를 클릭해야 피라미드가 나오잖아? 근데 클릭하지 않고도 그 탭이 일단은 같이 나와있고(물론 피라미드는 빈칸이겠지) '클릭 시 해당 OO(부서/사업부) 피라미드 분포 상세 확인 가능'이런식의 문구를 넣고싶어. 

직군별 인원현황에서 VDP직군, 미분류직군, G직군 지워. SM직군은 S로 분류해. '임원' 은 3명으로 카운트해. A직군(경영지원), S직군(영업), R직군(연구개발), E직군(기술), M직군(제조), T직군(제조전문)으로 바꿔. 
raw data의 '직급코드'에서 TJ, TA, TS인 사람은 T직군으로 분류해. 그래프에 현재 S직군과 R직군만 인원수와 %가 쓰여있는데 나머지도 써있게 해. 우측 상단에 '직급코드 기준, 총 350명'으로 문구 수정해.

'조직별 학력사항'에서 우측 상단의 '직속조직/우주연구소 x 최종학력' 문구 삭제해. '임원 0명 제외' 문구는 '임원 3명 제외'로 수정해. 현재는 표가 원그래프에 비해 위쪽에 배치되어있는데 표와 그래프 높이 맞게 조정해줘.

이번달은 '이동 세부 내역'이 많아서 카드가 너무 길어져서 그 옆에 있는 '인력증감내역' 카드도 함께 길어져버렸어. '이동세부내역'을 적잘하게 잘 나눠서 3개 정도의 카드로 나누고('부서별 인원현황'이나 '사업장별 인원현황' 사이즈로) '인력증감내역'카드와 함께 총 4개의 카드로 잘 배치해.


'부서별 인원현황' 카드에서 '타일 클릭 시 조직장 표시'를 '부서 클릭시 부서장 표시'라고 바꿔. 그리고 '우주사업단' 클릭하면 부서장을 '권태훈 (사업단장)'이 뜨게 해. '솔루션사업팀' 클릭하면 부서장을 '권태훈 (팀장)'이 뜨게해.

'부서별 레벨 분포'카드에서 '12개 부서 X 레벨 상세'라는 우측 상단의 문구 삭제해. '임원'칼럼 삭제해. '계약직' 칼럼 삭제해. 7~3의 숫자를 각각 'L7, L6, L5, L4, L3'로 바꾸고, 3은 'L3이하'로 바꿔. '기타(T직군)'을 추가해서 raw data 중 '직급명' 칼럼에서 '제주우주센터'의 'TJ(사원)'은 'L3이하'로 카운트해.

대시보드의 맨 아래에 'CSV를 업로드하면 자동 계산됩니다. 외부 서버로 전송되지 않고 브라우저 안에서만 처리됩니다.' 문구는 삭제해.

[Part2 수정사항]
 Part2에서는 '우주사업부 재직 인원' 카드를 '전사 재직 인원'으로 바꿀 것. '발령, 변동 건수' 카드는 삭제할 것. '평균 근속연수' 역시 우주사업부가 아닌 전사 인원으로 할 것(그룹입사일 기준, 임원 제외는 유지).

'사업부 매핑표에 없는 조직명' 이 경고창은 그냥 없애버릴 것.
'지원조직'에 '법무팀' 포함시킬 것. '해양'사업부에 'Smart Battleship체계팀' 포함시킬 것.
'사업부별 인원현황' 카드는 파이차트가 나을지 세로 막대그래프가 나을지 고민됨.

'사업부별 인원현황'에서 '지원조직' 조각을 누르면 '전략기획실, 재무실, HR실, 구매실, 법무실, 커뮤니케이션실, CR실, 원가실, 품질경영실, CISO실, ESH실, 경영진단팀'이 뜨게 해. '기타' 조각을 누르면 '사장실, 고문실, C-UAS실'이 뜨게 해. 

'사업부별 평균 연령' 카드의 막대그래프에서 우주만 색깔을 좀 다르게 하고 싶음. 우측 상단의 '한국나이 기준'이라는 문구를 '2026년 한국나이 기준'으로 수정.

'사업부별 임원현황' 카드와 '사업부별 임원 1인당 관할인원'을 계산할 때 각 사업부별로 임원을 어떻게 카운트하냐면 raw data에서 '직위코드명' 칼럼에서 '임원, 전무, 상무, 고문, 부사장'에 해당하면 임원으로 카운트해. 
'사업부별 임원 1인당 관할인원'은 '사업부별 인원현황'에 나와있는 인원을 '사업부별 임원현황' 카드에 나오는 임원수로 나눠.

'사업부별 레벨 피라미드' 역시 7~3의 숫자를 각각 'L7, L6, L5, L4, L3'으로 수정.
